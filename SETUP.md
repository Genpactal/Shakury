# Нұрдаулет & Манура — подключение RSVP к Google Sheets

Сайт уже содержит форму RSVP, музыку, сообщение об успешной отправке и поле количества гостей. Для реального сбора ответов нужно один раз подключить Google Sheets.

## 1. Создайте таблицу

Создайте пустую Google Таблицу, например **Нұрдаулет-Манура RSVP**.

Откройте **Расширения → Apps Script**.

## 2. Добавьте backend

Откройте файл `google-apps-script-Code.gs` из этого архива, скопируйте весь код и вставьте вместо содержимого `Code.gs` в Apps Script.

Сохраните и запустите функцию **setup** один раз. Google попросит разрешение на работу с вашей таблицей — подтвердите его.

После этого в таблице автоматически появятся два листа:

- **RSVP** — все ответы гостей;
- **Summary** — счётчики: количество ответов, сколько гостей придёт, сколько отказов и время последнего ответа.

## 3. Опубликуйте Web App

В Apps Script нажмите **Deploy → New deployment → Web app**.

Выберите:

- **Execute as:** Me
- **Who has access:** Anyone

Нажмите **Deploy** и скопируйте ссылку, которая заканчивается на `/exec`.

## 4. Вставьте ссылку в сайт

Откройте `index.html` обычным текстовым редактором и найдите строку:

```js
const GOOGLE_SCRIPT_URL = 'PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
```

Замените текст внутри кавычек на вашу ссылку `/exec`.

Пример:

```js
const GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

Сохраните файл. После этого ответы с сайта будут попадать в Google Sheets.

## Музыка

В сайт уже встроена спокойная инструментальная фоновая музыка. Браузеры блокируют автоматическое воспроизведение звука без действия пользователя, поэтому музыка запускается после первого нажатия по странице. Справа сверху находится кнопка **Музыка**, которой можно включать и выключать звук.

Файл `assets/music.mp3` также приложен отдельно, если позже понадобится заменить музыку.
